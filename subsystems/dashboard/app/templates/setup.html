Setup token required

First-run setup is locked until a setup token is configured, so nobody else can claim this server.

  1. Add a line like SETUP_TOKEN=<random value> to /etc/rustdesk-fleet/dashboard.env. Generate one with python3 -c "import secrets; print(secrets.token_urlsafe(24))".
  2. Restart the dashboard: sudo systemctl restart rustdesk-dashboard.
  3. Open /setup?token=<that value>.

Re-running install.sh does this for you and prints the URL.
